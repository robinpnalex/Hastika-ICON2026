# Task A prediction tables

This directory contains intermediate or evaluation-only prediction tables. They are not
the final released-test submission files; those are under `submissions/task_a/final/`.

| file | purpose |
|---|---|
| `ensemble_predictions.csv` | historical Task A validation predictions from the MuRIL/TF-IDF ensemble |
| `svm_predictions.csv` | historical Task A validation predictions from the SVM component |
| `task_a_validation_candidate_predictions.csv` | unattributed 806-row validation candidate moved here from the repository-level submissions folder; it scored 0.8970 accuracy against `data/raw/hastika_binary_validation.csv` |
